# 藏有计划 · 让收藏变成行动

小红书站内 AI 助手的场景化能力升级概念 Demo：以收藏夹作为 AI 理解任务的上下文，把收藏的笔记生成可执行的旅行计划；当收藏笔记的评论区出现新情况（如店铺装修、景点关闭）时，定位受影响的行程，给出调整建议，用户确认后再更新计划，并保留变更记录与撤销。

> 纯前端模拟 Demo：内容、价格、地点状态与分析结果均为演示数据，未接入小红书真实数据或任何模型。

## 运行

```bash
npm install
npm run dev
```

## 演示路径

1. 打开「云南旅行」收藏夹，点底部「问问 AI」，生成云南五日游计划。
2. 回到收藏夹，点「收藏笔记的评论区有新评论」，把「这家店最近在装修……11月底才重新营业」加入收藏夹。
3. 点「检查对行程的影响」：评论被定位到 Day 1 晚餐，并展示时间比对与判断依据。
4. 选择调整方式，在同页预览更新后的行程，点「确认更新」。
5. 在计划页查看变更标记，进入变更记录查看差异或撤销。

## 技术栈

Vite + React + TypeScript，状态由 `useReducer` + Context 管理，并持久化到 localStorage。
